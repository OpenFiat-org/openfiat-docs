# Руководства

Каждое руководство ниже — реальный, запускаемый пример [SDK](../sdks) —
протестированный в CI против живого узла, а не просто проза. Сначала запустите
локальный узел:

```bash
git clone git@github.com:OpenFiat-org/openfiat-core.git
cd openfiat-core
cargo run -p openfiat-cli -- --rpc-bind-address 127.0.0.1:7080
```

- **[Постройте торгового бота](trading-bot)** — опубликуйте объявление,
  откройте резервирование против него.
- **[Зарегистрируйте поставщика уведомлений](notification-provider)** —
  зарегистрируйтесь в реестре сервисов, сообщите о доставке.
- **[Зарегистрируйте поставщика оракула](oracle-provider)** — зарегистрируйтесь
  в реестре сервисов, опубликуйте подписанный обменный курс.
