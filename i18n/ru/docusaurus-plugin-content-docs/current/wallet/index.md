# Кошелёк

В веб-приложении OpenFiat,
[openfiat-app](https://github.com/OpenFiat-org/openfiat-app) (`/wallet`), есть вид
кошелька, и он всё ещё отрисовывает демо-данные — приложение переводится на живые
данные по одному маршруту за раз, и это не один из перешедших маршрутов.

Отдельный кроссплатформенный кошелёк (Android, iOS, Linux, macOS, Windows, Web)
остаётся отложенным. Заглушка для него в `openfiat-apps` так и не была
сформирована, и этот репозиторий больше не в активной разработке.

До тех пор узел никогда ничего для вас не держит и не подписывает: каждая мутация
— это полезная нагрузка, которую ваша собственная пара ключей подписывает локально
и отправляет — см. [именование методов](../api) и любой [SDK](../sdks) для
примитива подписи.
