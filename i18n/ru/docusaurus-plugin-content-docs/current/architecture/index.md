# Архитектура

OpenFiat — не блокчейн, это децентрализованный одноранговый протокол, построенный
поверх Solana. Solana обеспечивает безопасный, прозрачный ончейн-расчёт через
проверенные смарт-контракты; OpenFiat обеспечивает одноранговую сеть координации,
отвечающую за объявления, обнаружение сделок, зашифрованную связь, репутацию,
управление и уведомления.

## Слои

- **Слой сети** — обнаружение пиров, gossip, синхронизация снапшота/сессии, реестр сервисов (см. `openfiat-core/crates/{network,discovery,gossip,snapshot,sessions,registry}`).
- **Слой контента** — файлы, на которые указывают записи протокола, адресуемые по CID и подаваемые между узлами через bitswap (`crates/content`).
- **Слой сделок** — объявления, резервирования, расчёты, споры.
- **Слой доверия** — заявления об идентичности, репутация, анализ рисков.
- **Слой координации** — управление, уведомления, оракулы.

Каждый из них работает внутри одного процесса и, на проводе, поверх одной
идентичности libp2p — без второго демона и без второго peer id. Обнаружение и
gossip мультиплексируются поверх одного соединения и маршрутизируются раздельно по
номеру спецификации OFS, который несут их конверты; подача контента говорит на
стандартном `/ipfs/bitswap/1.2.0` в том же swarm, что и позволяет любому пиру IPFS
получать контент протокола прямо с узла.

См. [эталонную реализацию](https://github.com/OpenFiat-org/openfiat-core) для
текущей разбивки на уровне крейтов и
[`docs/architecture.md`](https://github.com/OpenFiat-org/openfiat-core/blob/main/docs/architecture.md)
там для графа зависимостей крейтов, формата провода и транспорта.
