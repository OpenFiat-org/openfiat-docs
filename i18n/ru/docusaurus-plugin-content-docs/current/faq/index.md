# Частые вопросы

**OpenFiat — это блокчейн?**
Нет. OpenFiat — это одноранговый протокол координации, построенный поверх Solana,
которая занимается расчётами.

**Нужен ли моему узлу отдельный демон IPFS?**
Нет. Узел подаёт контент протокола сам, поверх своей собственной идентичности
libp2p, и это включено по умолчанию — `--ipfs-api-url` и демон Kubo больше не то,
как это работает. См. [подача контента](../node-operators/content-serving).

**Должен ли я перечислять каждый пир, с которым мой узел должен говорить?**
Нет. `--entrypoint` устанавливает первое соединение; после этого узел узнаёт
пиры, которые ему никогда не давали, и анонсирует адреса, по которым он достижим.
См. [обнаружение пиров](../node-operators/peer-discovery).

**Кто управляет OpenFiat?**
AllenHark ведёт первоначальную разработку и финансирует ранний рост, с явной
долгосрочной целью прогрессивной децентрализации — см.
[Предисловие](../whitepaper) и главу 24 (Управление и эволюция протокола).

**Под какой лицензией код?**
Apache License 2.0, во всех репозиториях
[OpenFiat-org](https://github.com/OpenFiat-org).
