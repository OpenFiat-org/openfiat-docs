# व्हाइटपेपर

पूर्ण व्हाइटपेपर — प्रस्तावना से अध्याय 27 (निष्कर्ष) तक —
[openfiat-specs](https://github.com/OpenFiat-org/openfiat-specs) में सत्य के स्रोत
के रूप में अनुरक्षित है। यह साइट उसे दोहराने के बजाय उससे लिंक करती है, ताकि
व्हाइटपेपर अपनी विहित प्रति से कभी असंगत न हो।
