# ट्यूटोरियल

नीचे का हर गाइड एक असली, चलाने-योग्य [SDK](../sdks) उदाहरण है — केवल गद्य नहीं,
बल्कि CI में एक जीवंत नोड के विरुद्ध परीक्षित। पहले एक स्थानीय नोड शुरू करें:

```bash
git clone git@github.com:OpenFiat-org/openfiat-core.git
cd openfiat-core
cargo run -p openfiat-cli -- --rpc-bind-address 127.0.0.1:7080
```

- **[एक ट्रेडिंग बॉट बनाएँ](trading-bot)** — एक विज्ञापन प्रकाशित करें,
  उसके विरुद्ध एक आरक्षण खोलें।
- **[एक सूचना प्रदाता पंजीकृत करें](notification-provider)** —
  सेवा रजिस्ट्री में पंजीकृत करें, एक डिलीवरी रिपोर्ट करें।
- **[एक ऑरेकल प्रदाता पंजीकृत करें](oracle-provider)** — सेवा रजिस्ट्री में
  पंजीकृत करें, एक हस्ताक्षरित विनिमय दर प्रकाशित करें।
