# 协议规范

每一份 OpenFiat 协议套件（OFS）文档都以可供实现的细节定义一个
协议组件。所有规范都位于
[openfiat-specs/Whitepaper/Specifications](https://github.com/OpenFiat-org/openfiat-specs/tree/main/Whitepaper/Specifications)。
