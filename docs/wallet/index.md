# Wallet

The OpenFiat wallet is a planned cross-platform application (Android, iOS,
Linux, macOS, Windows, Web) tracked in
[openfiat-apps/wallet](https://github.com/OpenFiat-org/openfiat-apps/tree/main/wallet).
It has not been scaffolded yet — this section will grow into setup and usage
guides once implementation begins.
