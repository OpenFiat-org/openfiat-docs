## About

`openfiat-docs` is the developer documentation site at
[docs.openfiat.network](https://docs.openfiat.network) — a
[Docusaurus](https://docusaurus.io) 3 site (React 19, TypeScript). The
homepage ships a real `curl` request/response against the protocol's
JSON-RPC API rather than generic marketing copy, and a quick-links section
into the Protocol/API/SDK docs below.

The docs themselves are organized as one category per audience — real
directories, not a plan: `architecture`, `whitepaper`, `protocol-specs`,
`sdks` (quickstarts for both the Rust and TypeScript `openfiat-sdk`
packages), `wallet`, `merchants`, `node-operators`, `api` (the OFS-8200 API
specification), `tutorials`, `faq`. The sidebar itself is autogenerated from
that directory structure (`sidebars.ts`), not hand-maintained.

For the protocol's own design and specification text, see
[openfiat-specs](https://github.com/OpenFiat-org/openfiat-specs) — this site
documents how to build against the protocol, not the protocol's design
rationale.

## Repository layout

```
.
├── docs/                  # architecture, whitepaper, protocol-specs, sdks,
│                           # wallet, merchants, node-operators, api, tutorials, faq
├── src/
│   ├── pages/              # homepage (real JSON-RPC example, not a mock)
│   ├── components/         # HomepageFeatures (Protocol/API/SDKs quick links)
│   └── css/custom.css      # theme tokens
├── static/
├── tests/
├── docusaurus.config.ts
└── sidebars.ts
```


## Quick start

```bash
pnpm install
pnpm start
```

Open http://localhost:3000.


## Development

Requires Node.js 20+ and pnpm.

```bash
pnpm lint       # eslint .
pnpm typecheck  # tsc
pnpm build      # docusaurus build
```


## Testing

```bash
pnpm test       # vitest run
```
